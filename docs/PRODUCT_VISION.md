# PsiNote Product Vision

## One-sentence product

PsiNote helps a psychologist know what requires attention now, understand each person's trajectory and create a reliable professional record without turning documentation into a second job.

## North-star experience

When opening PsiNote, the professional should immediately know:
- who they will see today;
- what is late or unfinished;
- where to resume a person's follow-up;
- what happened recently;
- what needs to be documented, delivered or reviewed.

## Core product objects

- People under follow-up
- Follow-up/intake context
- Plans/objectives
- Appointments
- Sessions
- Professional records/evolution
- Restricted materials where justified
- Documents and immutable versions
- Consents/acknowledgements
- Tasks/follow-up items
- Audit events

## Navigation hypothesis

TODAY
- Today
- Agenda

CARE
- People
- Sessions

DOCUMENTATION
- Documents
- Reports

MANAGEMENT
- Settings

ADMINISTRATION
- Administration (only with trusted privilege)

This hierarchy is a hypothesis to validate through implementation and usability testing; it is not a menu redesign for its own sake.

## Definition of useful

A feature is useful only if it reduces operational effort, improves continuity, protects information, prevents omission or supports a legitimate professional/documentation need.

A feature is rejected when its primary value is decorative, duplicates another workflow or increases collection of sensitive data without a clear purpose.
